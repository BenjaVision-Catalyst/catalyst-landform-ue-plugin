# Current Landform documentation

The plugin's supported assembly interface is the **Planet** editor. Begin with
[installation](../README.md), [UE 5.8 Mac qualification](UE58Installation.md), [Planet authoring](PlanetLandforms.md),
[province placement and geological preference relaxation](ProvinceLandforms.md),
and [the packaged radial guides](RadialGuides.md).

The [approved cave study](SpatialCavePrototype.md) and its original captures are
visual references. Other dated study and qualification documents record historical
workloads and decisions; they do not select an alternate editor or generator and
are not visual acceptance of the current family. Retired experimental generation
and standalone terrain-editor implementations have been removed from the plugin.
